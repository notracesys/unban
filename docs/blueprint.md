# **App Name**: ShadowProtocol

## Core Features:

- Decision Tree Diagnostics: An interactive step-by-step analyzer to identify ban types (Automatic, Manual, or Reincident) before initiating recovery.
- Smart Ticket Repository: Access to specialized, battle-tested ticket templates with one-tap copy functionality to ensure structural compliance.
- Contextual Ticket Advisor Tool: A generative AI tool that recommends the most strategic ticket model based on the user's specific account restriction details.
- Strategic Delay Timer: A built-in counter that calculates and manages the cooldown periods between ticket attempts to avoid system flagging.
- Human Response Decoder: A guide-driven interface that helps users identify if a platform response was generated by an AI bot or a human analyst.
- Status Log Persistence: Allows users to track their unban attempts and steps taken using a local storage or database solution.

## Style Guidelines:

- Primary color: High-alert 'Protocol Red' (#FF2E2E) to evoke urgency and strategic importance.
- Background color: 'Nervous System Onyx' (#0F0A0A), a deep, dark desaturated red that creates a secretive, underground vibe.
- Accent color: 'Deep Amber' (#D46F15), analogous to the red primary, providing high-contrast for warning labels and critical navigation.
- Headline font: 'Space Grotesk' for a computerized, techy aesthetic; Body font: 'Inter' for clear readability in dense instructional sections.
- Code font: 'Source Code Pro' specifically for the ticket models to mimic terminal input commands.
- Sharp, linear vector icons following a technical HUD (Heads-Up Display) aesthetic.
- A focused 'briefing' layout using narrow text containers and horizontal dividers to simulate reading a high-security document.
- Subtle digital 'glitch' effects on hover and typing-reveal animations for newly opened instructional steps.
